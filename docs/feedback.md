# Feedback
- **Discussions** — interpretation, alternative models, applications, theoretical objections.
- **Issues** — failed reproduction, suspected numerical error, reference correction, documentation defect. Please give the claim id (`ledgers/status.yaml`) or run script, your reasoning or evidence, and whether you reproduced anything.
- **Pull requests** — code, tests, documentation, independently reproduced outputs.
External suggestions enter the ledger as `open` and become `result` only after independent check.
